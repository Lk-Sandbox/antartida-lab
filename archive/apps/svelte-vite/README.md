# svelte-vite

Vite + Svelte 5 (runes). Reescritura de los componentes de `react-ui` en Svelte, con la misma lógica, contenido, estilos y SVG de `@antartida/core`.

```sh
pnpm dev       # http://localhost:5104
pnpm build && pnpm preview   # http://localhost:5104
pnpm typecheck # svelte-check
pnpm e2e
```
