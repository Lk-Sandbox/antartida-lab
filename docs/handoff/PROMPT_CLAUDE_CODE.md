# Prompt inicial para Claude Code

Leé `HANDOFF.md` y `design/Main.dc.html` completos. El HTML es un prototipo en un formato de canvas de diseño: no lo copies, usalo como referencia exacta de look, textos, datos y comportamiento.

Implementá "Antártida por descubrir" con Astro + una isla React/TypeScript, según la estructura y los criterios de aceptación del handoff. Antes de escribir código, armá un plan por etapas (1: proyección y mapa estático, 2: pan/zoom/clustering, 3: lista y fichas, 4: transición, 5: expedición, 6: accesibilidad y tests) y frená hasta que lo apruebe.

Reglas: código en inglés, documentación y commits en español con Conventional Commits, tests en cada etapa, sin inventar contenido científico.
